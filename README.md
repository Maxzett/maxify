# Maxify · Red social

Trabajo Práctico N.º 2 de **Programación IV** (UTN Avellaneda).

Monorepo con dos proyectos:

- `frontend/`: Angular
- `backend/`: NestJS + MongoDB

## Ramas

- `main`: versión oficial, la que se despliega.
- `develop`: integración del desarrollo.
- `sprint-N`: una rama por sprint, creada desde `develop`.
